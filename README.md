# موقع برجراية

موقع عربي متجاوب مبني على مشروع Kopi-Coffee-Git المرجعي، مع الحفاظ على أقسام الموقع والسلة وإتمام الطلب.

## التشغيل

1. ثبّت Node.js.
2. افتح هذا المجلد في الطرفية وشغّل `npm install`.
3. شغّل `npm run dev` لفتح الموقع محليًا.
4. استخدم `npm run build` لإنتاج نسخة النشر داخل `dist`.
